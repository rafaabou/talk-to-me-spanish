# Talk To Me Spanish — app

Flutter app source for Talk To Me Spanish (`com.rafaabou.eszero_hero`). See the repository root [README](../README.md) for features, architecture, build pipelines, and release instructions.

## Local development

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

Course content lives in `assets/course/` (72 lessons, A1–C2) and is generated by the Python pipeline in `../tools/`.
